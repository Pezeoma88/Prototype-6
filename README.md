# CarpoolBoard — Prototype 6

**Share the Ride. Split the Drive.**

CarpoolBoard is a campus carpooling mobile application designed to help college students find rides, offer transportation, and coordinate travel more conveniently.

Built with **React Native, Expo, and Supabase**, CarpoolBoard allows students to participate as Drivers or Riders through a simple, user-friendly interface.

## About the Project

CarpoolBoard is being developed as part of a Mobile App Development course at Southern Methodist University (SMU).

Prototype 6 focuses on improving the user interface and overall experience of creating and managing rides, with an emphasis on simplifying the **Offer a Ride** workflow.

## Features

### Driver Mode
- Create and post rides for other students.
- Search for destinations using a searchable selection field.
- Choose a pickup location.
- Select a departure date and time.
- Adjust available seats from 1 to 7.
- Edit existing ride details.
- View a confirmation screen after posting or updating a ride.
- Review and manage incoming ride requests.

### Rider Mode
- Browse available rides.
- View ride information and available seats.
- Request a seat on an available ride.
- Explore pickup locations and routes.
- Switch between Rider and Driver modes.

### User Profiles
- Sign in or create an account.
- Edit profile information.
- Add a profile picture.
- Update driver and vehicle information.
- Save profile information using Supabase.

### Interactive Map
- Explore available pickup locations.
- View routes and destinations.
- Help drivers and riders coordinate meeting points.

## What's New in Prototype 6?

The primary focus of Prototype 6 is a redesigned **Offer a Ride** experience.

### 1. Searchable Destinations
Replaced the long destination selection list with a searchable field. Users can quickly find a destination or enter their own.

### 2. Improved Ride Form
Reorganized the form with a cleaner layout, including more compact route information and side-by-side date and time fields.

### 3. Seat Selection
Added a seat stepper that allows drivers to select between 1 and 7 available seats.

### 4. Pickup Location Validation
Drivers must select a pickup location before submitting a ride.

### 5. Ride Confirmation
Added a confirmation screen that appears after successfully posting or updating a ride, with options to return home or edit ride details.

### 6. UI/UX Improvements
Used Figma and Figma Make to explore interface improvements before implementing the updated design in React Native.

## User Testing

Prototype 6 focuses on evaluating the updated ride creation workflow, navigation, and map features.

### Testing Instructions

1. Sign in or create an account.
2. Switch to Driver mode.
3. Select **Offer a Ride**.
4. Choose a destination, pickup location, departure date/time, and number of seats.
5. Post the ride and review the confirmation screen.
6. Edit the ride to test the updated workflow.
7. Explore the Map tab.
8. Switch to Rider mode and browse available rides.

### User Testing Questions

1. How easy was it to create and edit a ride? Did the searchable destination field and seat selection make the process easier?
2. How useful were the map and pickup locations when exploring rides? Was the navigation straightforward?
3. What improvements would make CarpoolBoard more convenient for college students?

## Design Process

For Prototype 6, I used Figma and Figma Make to evaluate the existing Offer a Ride interface and explore ways to improve the user experience.

The design process included reviewing the existing workflow, identifying usability issues, creating a redesigned interface, and implementing the changes in React Native.

The exported Figma Make prototype was used as a design reference rather than directly replacing the mobile application code.
